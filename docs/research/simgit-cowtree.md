## simgit

1. **Real worktree and shared blocks.** Git registers the target using `worktree add --no-checkout`. simgit materialises a separate baseline for the requested commit using a private `GIT_INDEX_FILE`, `read-tree`, and `checkout-index --all --force -u`. On macOS it clones the whole baseline directory with `clonefile`; a per-file clone path is available. The `.git` pointer is saved, the empty target removed, then the pointer restored inside the cloned directory. Files consequently share with the baseline, not the source checkout. [Registration and population](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/src/commands/worktree.rs#L392-L443), [baseline construction](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/src/commands/worktree/cow.rs#L159-L242), [directory replacement](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/src/commands/worktree.rs#L637-L681).

2. **Different commits and index.** A different target commit gets its own full baseline. simgit copies that baseline's index and rewrites stat fields to match the clone, retaining strict Git change detection. Its writer accepts SHA-1 index versions 2 and 3. Other formats fall back to Git's `read-tree`, with a more expensive initial scan. [Index implementation](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/src/commands/worktree/index.rs#L1-L110). This complexity followed a measured failure: [v0.1.6](https://github.com/abendrothj/simgit/releases/tag/v0.1.6) explicitly retracts its relaxed-stat optimisation as ineffective; [issue 20](https://github.com/abendrothj/simgit/issues/20) reports setup time separately from first status. The correction is [7903652](https://github.com/abendrothj/simgit/commit/79036527be2889e9c9582ca85aad4c81326fc2e2).

3. **Working state and metadata.** Baselines use committed objects, so staged, unstaged, untracked and ignored source files are not copied. There is no source-cleanliness requirement in creation. Tests assert symlink targets, executable bits, filtered content, a clean initial status and subsequent edit detection. Per-file population recreates symlinks. macOS clones receive baseline metadata; there is no explicit xattr/ACL preservation policy or test in the inspected population code. [Materialisation test](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/tests/cli_workflow.rs#L521-L588), [filter fixture and assertions](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/src/commands/worktree_tests.rs#L593-L687), [file kinds](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/src/commands/worktree/cow.rs#L299-L347).

4. **Conversion.** No existing-worktree storage conversion command exists in the inspected command surface. Baseline cloning cannot satisfy the requested in-place conversion requirement. [Command implementation](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/src/commands/worktree.rs).

5. **Failures and concurrency.** An actual clone probe precedes mode selection. Creation coordinates destination claims and branch claims; baseline publication uses a unique temporary directory, atomic rename and cache locks. Tests cover concurrent registration, competing branches, incomplete baselines and prune recovery. Population errors invoke worktree rollback; several temporary-file cleanup errors are discarded. Root-clone recovery recursively deletes the target without a durable ownership journal, leaving an external-write and abrupt-termination concern. No injected disk-full coverage was found. [Probe](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/src/commands/worktree/cow.rs#L19-L39), [claims](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/src/commands/worktree/locks.rs#L128-L253), [concurrency assertions](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/tests/cli_workflow.rs#L1306-L1430), [baseline recovery tests](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/src/commands/worktree_tests.rs#L411-L499).

6. **Git compatibility.** Creation supports detached HEAD, new and existing branches, linked sources, and explicit cone-mode sparse checkout; sparse overlay mode is rejected. Filters execute during baseline construction. A baseline is keyed only by commit, so changed filter configuration or path-dependent filter output can make cached materialisation inappropriate: this is an inference from its key and checkout context. The README's broad hook compatibility claim exceeds the creation evidence: the CoW path has no explicit `post-checkout` invocation after `--no-checkout` registration. No submodule or LFS acceptance test was found. Path discovery decodes UTF-8 strings and trims them, so arbitrary byte names and trailing whitespace in root paths are not established as safe. [Sparse path](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/src/commands/worktree.rs#L245-L250), [linked-source test](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/src/commands/worktree_tests.rs#L971-L994), [path decoding](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/sg/src/commands/worktree.rs#L1537-L1562).

7. **Savings and writes.** Published measurements distinguish `du` accounting from volume used-block deltas after sync and settling, warn about unrelated volume writes, and include baseline cost. A separate script measures the first durable overwrite using `fsync`. These are upstream measurements, not reproduced results; volume deltas remain noisy and do not identify every file's shared extents. The materialisation test checks edit detection, but does not itself prove shared allocation or two-way byte independence. [Measurement method](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/docs/scaling_benchmark.md#L1-L64), [I/O benchmark](https://github.com/abendrothj/simgit/blob/bcb419bf0d4bfd71c82cf8913e2fa3c0848f572f/tests/bench_worktree_io.py).

## cowtree

1. **Real worktree and shared blocks.** Registration delegates to installed Git with `--no-checkout --lock`. cowtree inventories registered donor trees, clones verified files with `fclonefileat`, and optionally clones exact subtrees into private temporary directories before publication. It requires at least one clone for a nonempty checkout and fails without a silent full-copy fallback. [Registration](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/src/create.rs#L204-L285), [seeding and completion](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/src/create.rs#L288-L536).

2. **Different commits and index.** The target index comes from `read-tree --reset <target>`. Same-path, same-object regular files are donor candidates even across different commits. Candidate materialised bytes must hash to the expected raw Git blob. Git writes every remaining path using `checkout-index --index`, refreshes the index and verifies status. This avoids importing a donor's index. Transforming attributes and CRLF policies exclude files from cloning and let Git materialise them. [Attribute screen](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/src/create.rs#L638-L690), [raw blob verifier, including SHA-256](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/src/git.rs#L110-L141).

3. **Working state and metadata.** Dirty donor files fail byte verification. Untracked and ignored files are omitted; directory clones must contain exactly the expected entries. Symlinks and gitlinks go through Git's native representation. Creation applies target checkout permissions and umask, uses `CLONE_NOOWNERCOPY` with destination ACL inheritance, resets timestamps and rejects donor flags or user xattrs. Tests cover native permission parity, dirty donors, user xattrs, hooks, filters and sparse modes. Existing-worktree compaction skips nonregular and dirty paths, verifies bytes even when `assume-unchanged` hides edits, preserves target mode/atime/mtime, and leaves xattr-bearing files unmodified. It does not implement arbitrary target ACL or xattr copying. [Native clone metadata rules](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/src/platform/macos_create.rs#L120-L253), [compaction preservation test](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/tests/apfs.rs#L395-L524).

4. **Conversion.** `compact` inventories target HEAD and other registered worktrees, skips paths reported dirty by `diff HEAD`, and finds same-path, same-blob donors on compatible APFS volumes. Before replacement it hashes both donor and target raw bytes, rejects nonordinary metadata and checks identity changes. It clones into a unique sibling, restores mode/times, rechecks target identity and renames over the target. Converted paths retain their names and Git registration. Transformed files whose raw bytes differ from their blob are skipped even if two worktrees contain identical transformed bytes; this is conservative but misses valid savings. Dry-run counts candidates before materialised-byte and metadata verification, so it can overestimate. [Planner](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/src/compact.rs#L143-L260), [replacement](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/src/platform/macos.rs#L204-L340).

5. **Failures and concurrency.** Creation records owned inode identities, handles SIGINT/SIGTERM, joins workers and retains an incomplete locked worktree after materialisation starts. It avoids deleting files a failed filter might have created. Tests exercise filter failure, interruption, seeded-file interference and renamed ancestors. Compaction checks source and target identity around cloning, but uses path-based `clonefile` and `rename`; its final check/rename gap remains. There is no operation lock or durable replacement journal in the inspected compaction path, no temporary-clone content hash after the syscall, and no explicit fsync protocol. Failed cleanup discards removal errors. Retry recognises stale siblings by filename/PID and tracked/untracked context rather than a persisted ownership record. No disk-full injection test was found. [Creation cleanup](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/src/create.rs#L68-L201), [interruption test](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/tests/create.rs#L728-L801), [stale cleanup](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/src/platform/macos.rs#L76-L186).

6. **Git compatibility.** Installed Git retains worktree registration and option semantics. Creation explicitly invokes the post-checkout hook after successful materialisation; hook failure retains the usable worktree and propagates its exit status. Tests cover sparse cone/noncone, filters, relative hook paths, unusual byte names, detached linked donors, SHA-256 repositories, empty/orphan cases and nonrecursive gitlinks. This does not establish recursive populated submodule support or Git LFS installation behaviour. Creation removes Git environment selectors before target operations; the separate compaction Git helper directly inherits the environment, so an ambient `GIT_INDEX_FILE` remains a concern there. [Compatibility tests](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/tests/create.rs), [Git environment handling](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/src/add.rs#L36-L59), [compaction helper](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/src/git.rs#L28-L53).

7. **Savings and writes.** Tests assert distinct inodes and two-way byte independence after creation, and changed inodes with preserved bytes/mode/mtime after conversion. A receipt records completed cloning, not a live extent map. `compact --all` skips current receipts unless `--recompact` is supplied; an explicitly named target is processed again. The planner reports eligible allocated bytes using `st_blocks * 512`, which includes shared blocks. Upstream benchmarks explicitly measure command time, use warm caches and disclaim proof of unique physical savings. The README's “up to 95%” remains a claim in this investigation. [Independence test](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/tests/create.rs#L133-L183), [repeat tests](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/tests/apfs.rs#L152-L300), [benchmark limitations](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/benchmarks/README.md#L254-L270).

## Decisions informed by these projects

Adopt installed Git for registration and index construction, object IDs as candidate hints, materialised-byte verification, explicit metadata eligibility, exact ownership checks, and creation failure states that preserve potentially user-owned files. Measure first status and subsequent writes alongside setup, and report eligible bytes separately from measured volume allocation.

Avoid source-wide clone followed by reset, silent full-copy fallback, custom index rewriting in the first release, cache keys that ignore checkout representation, and filename-shaped recovery authority. cowtree's own [rejected recursive-clone experiment](https://github.com/markjaquith/cowtree/blob/82336e3bcb5e9c28018529e58a0c515aa3617fe0/benchmarks/README.md#L380-L438) found additional complexity without a representative small-file speedup.

Resolve locally before shipping: replacement durability and journal ownership; native target ACL/xattr preservation or explicit conservative skips; syscall race limits under external writers; exact exclusion metadata provenance; filters and hook parity; and volume-allocation benchmarks with enough payload to rise above APFS metadata and background noise. Neither inspected project implements the requested Time Machine lifecycle.
